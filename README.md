# 穗易办 静态版（v0.1.3）

这个目录是完全独立的前端部署包，不需要启动后端：

- 直接双击 `index.html` 即可打开
- 也可以把整个目录上传到 GitHub Pages / Netlify / Cloudflare Pages，即可获得公网网址
- 数据来自 `data/policies.js`，前端逻辑在 `assets/app.js`

站点定位：面向全国的补贴与办事指南数据站（当前首批覆盖广州）。v0.1.3 静态版内置 **170 条**广州补贴和办事数据（48 条人工种子 + 94 条官网采集），全部标注「待核验」；品牌与版本号已统一为「穗易办 · 全国补贴办事指南 v0.1.3 验证版」。

v0.1.1 变化：政策库新增城市筛选；项目根目录新增了 Python 后端（FastAPI + SQLite），提供政策核验、自动爬取和 AI 教程能力。静态版不依赖后端，适合快速演示；需要动态功能时，请使用项目根目录的完整版。

## 数据说明

- 静态版默认**不请求后端**，固定显示本地 `data/policies.js` 中的数据
- 数据更新后，在项目根目录的 `backend/` 下运行以下命令，即可把数据库最新条目同步到本目录：

```powershell
python scripts/export_policies_js.py
```

- 若需要在静态版中接入后端 API（如部署方自建后端），可在页面加载前设置 `window.API_BASE` 指向后端地址，例如在 `index.html` 的 `<script>` 之前加入：

```html
<script>window.API_BASE = "https://your-domain.com/api/v1";</script>
```

## 与完整版的区别

| 能力 | 静态版（本目录） | 完整版（项目根目录） |
| --- | --- | --- |
| 运行方式 | 双击打开 / 静态托管 | 需启动 Python 后端 |
| 数据来源 | 本地 `data/policies.js` | 后端 API（不可用时回退本地数据） |
| 实时采集 | 无（需重新导出同步） | 每日自动采集 + 手动触发 |
| 人工核验 | 无 | 核验台双人核验工作流 |
| 适用场景 | 快速演示、免费静态托管 | 正式运营 |
